# TaskFlow Pro

![Version](https://img.shields.io/badge/version-2.1.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

**TaskFlow Pro** is a premium, high-performance productivity application built with PHP and Tailwind CSS. It combines task management, project tracking, and activity logging into one seamless experience.

## 🌟 Key Highlights
- **Kanban Board**: Drag-and-drop project management.
- **Productivity Analytics**: Visual charts for task tracking.
- **Activity Center**: Complete audit trail of system actions.
- **Dynamic Branding**: Fully customizable app name via settings.
- **Premium UI**: Modern light theme designed for heavy daily use.

## 🛠️ Tech Stack
- **Server**: PHP 7.4+ (Native)
- **Database**: MySQL (PDO)
- **Styling**: Tailwind CSS
- **Interactivity**: Vanilla JavaScript
- **Charts**: Chart.js
